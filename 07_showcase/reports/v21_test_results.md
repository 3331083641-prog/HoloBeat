## 使用作品和故障场景

Chrome 从抽卡和装卡进入 BEAT，播放并测量 Holo Motion，发送到 PINBALL 的编曲演出；在自由弹珠中落球、录制碰撞、量化并合并回 BEAT。将同一首作品送入 FORGE，关闭网络连接时铸造 #MY-01，再次打开后从 IndexedDB 恢复。拆封、更改贴纸并生成带父作品关系的 #MY-02。通过实际按钮导出 PNG、WAV、WebM、V3 工程文件；通过文件输入导入，损坏工程被拒绝。创作和导出阶段归档服务处于关闭状态。

另起临时 SQLite 服务后，强制分享请求返回 503。客户端执行了一次有界重试，两次分享失败后，页面显示“作品已成功归档，但分享链接创建失败。”，库中仍只有一张。恢复服务后复用有效链接，打开 HTML 展页，获取 JSON，撤销后两个地址均为 404。人为断网期间记录 0 次静态资源获取失败，注入的分享 503 记录 2 次；这些预期故障保存在机器指标中，其他控制台报错为 0。

## 迁移与持久化

- SQLite 新库、v0 升级、重复升级、中断重开、损坏文件、重复编号/幂等键、锁定不可写、父子关系、分享过期及撤销均以独立库执行。旧 V3 作品归档 201，从浏览器旧收藏迁移再归档 200，行数保持 1；修改真实内容仍会触发 409。
- IndexedDB 真实事务 abort、升级 blocked、禁用存储、localStorage 写入超额、两种存储都失败、双击、重试和刷新均有断言。另在 Chrome 和 Edge 分别验证两个同源标签同时铸造同一份内容，确认只分配一个编号。
- 历史 A/B 步进、力度、时值和 soundSeed 通过工程归档、迁移、重混、重新导入校验。旧 PCM 标志失效后，由当前渲染器重新生成的波形通过缓存回读；独立授时的会话也验证了暂停、恢复、重复停止、切后台和停止后的静音。
