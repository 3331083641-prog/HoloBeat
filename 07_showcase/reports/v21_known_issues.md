# HoloBeat 当前运行边界

- 浏览器测量使用 Windows 桌面 Chrome 和 Edge 的无头模式、新建浏览器配置、Web Audio 输出和实际文件解码。Canvas 数据是浏览器绘图调用与声音调度的时差，不含声卡、蓝牙和显示器延迟。OPUS 编码、视频取帧和系统调度会使 WebM 与 PCM 时长略有差异。
- 后端仅在本机可用。HTML 展页和 JSON 分享均可在本机打开并撤销。现有 FORGE 提供创建分享的按钮，撤销和自选到期时间通过本地 API/客户端调用。部署到其他设备需要单独设计鉴权和资源所有权。同机进程属于默认信任范围。
- 新版归档限制 120 秒的作品、每组最多 4096 个事件、128 个贴纸和 1 MiB 请求体。离线音频渲染有 180 秒含效果尾音的上限。同轨过密的同时发声超过当前渲染器限额时会报告错误。
- SQLite 升级时会保留同目录备份。独立编辑而冲突的收藏、无法解析的 JSON 或损坏数据库需要在副本中核对。历史归档曾丢失的字段只能通过完整本地工程取回。已有目录及自定义数据库路径沿用原权限，Windows 新建默认目录才设置限制 ACL。
- IndexedDB 被长期占用时，需要关闭占用旧数据库的标签页，随后重试。主库和降级镜像各自独立产生不同新修订时，会保留两边并报告冲突。Chrome/Edge 使用 Web Locks 保护跨标签写入；缺少 Web Locks 的浏览器只有同页队列，本次未验证这些浏览器的多标签写入。
- 自由弹珠界面显示最近八秒碰撞。发送到量化或 FORGE 后才进入作品状态。直接刷新或离开该界面可能清空尚未发送的临时录音。原页面的碰撞回调只写组件本地状态，本轮按要求保留 Antigravity 的页面实现。
- 双存储均无法写入时，作品仍在当前标签页的草稿中。在这种状态下关闭标签页或刷新可能丢掉尚未持久化的修改，可从 FORGE 导出工程文件。
- 前端生产构建仍有 Vite 的主包体积和静态/动态导入提示。项目没有后端 `/generate` 接口；验收探测该路径的预期响应为 404。创作和音频生成在浏览器中运行。
