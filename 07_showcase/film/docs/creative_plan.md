## 2. 贯穿全片的核心主角与两代同源作品

### 核心声卡主角
- **`#05 二八大杠车铃`（SSR · 棱镜光带 · 市井脆响）**
  - 视觉识别：拉丝黄铜半球铃罩、笑脸表情、薄荷绿拇指拨片、橘红铆钉底座与三道声波弧，在奶油底与深黑舞台皆一眼可辨。
  - 听觉识别：双谐波调频铜铃音色清脆灵动，从单卡试听、四轨编曲、弹珠回弹到剧场铜铃双环，全程自带听觉签名。

### 主作品（原创首发 `#MY-01`）
- **作品名**：`《铃响晴巷》`
- **音乐设定**：`118 BPM` · `C 五声调式` · `2 小节独立 A/B 乐句（32 步）` · `摇摆度 18%`
- **四轨编制**：
  1. **街头律动（紫 `#7C3AED`）**：`#01 弄堂竹板梆子` — 木击底鼓骨架
  2. **市井脆响（橙 `#FF5C2B`）**：`#05 二八大杠车铃` — 反拍切分与 B 段加花主角
  3. **霓虹旋律（绿 `#00D4AA`）**：从 `#09 像素街机投币` 换卡升级为 `#11 赛博古筝拨弦` — 东方五声跃动主旋律
  4. **烟火氛围（黄 `#FFD60A`）**：`#13 夜市铁板滋啦` — 暖感复古和弦与市井热气铺底
- **闪卡外观**：`UR` 稀有度 · `温暖金箔` 箔面（经 5 种材质巡礼对比后选定，与黄铜车铃相得益彰）· 3 枚哑光市井贴纸（双片竹板、全息星芒、双连音符，置入安全边缘不遮面部与声纹）。

### 拆封重混第 1 代新作（`#MY-02`）
- **作品名**：`《铃响晴巷 · 夜行版》`（谱系：`#MY-01 → 第 1 代`）
- **可辨认改编**：从 `#MY-01` 拆封还原音乐后，将氛围轨换为 `#15 港风霓虹电流`、调式切为 `C 小调`、速度提至 `124 BPM`、开启「街巷回声」并对 B 段应用规则变奏「加密」，箔面切换为 `定向激光`，形成明暗日夜对比的听觉与视觉呼应。

## 4. 视觉、动效与声音准则

- **色彩严格承袭**：奶油纸基 `#F7F3E9`、象牙白 `#FFFDF8`、燕麦凹槽 `#EDE7D9`、深墨线 `#1A1A1F`、深黑舞台 `#14151B`、四轨语义色（紫 `#7C3AED` / 橙 `#FF5C2B` / 薄荷绿 `#00D4AA` / 黄 `#FFD60A`）。
- **克制包装边界**：新增转场与片头片尾作为影片视觉表达，完整 UI 镜头保持清晰正视构图与文字可读，不冒充原生功能。
- **配音与混音**：选用自然清亮带笑意的普通话神经人声，48 kHz 统一采样率制作，产品原声为核心，轻巧辅助节奏衬底仅在纯旁白过渡处轻托，任何产品音色展示、对比、变奏与剧场段落均让位产品真声。
