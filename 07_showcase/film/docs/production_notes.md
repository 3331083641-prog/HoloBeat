## 4. 音频与视觉素材来源说明

1. **产品界面与原声**：100% 采集自当前真实运行的「声卡造物局」Web 工作台与本机归档服务（Web Audio API / Tone.js 程序化声音合成，受中国街巷日常声景启发，非田野录音或非遗采样）。采用浏览器原生 `MediaRecorder`（48 kHz）+ CDP 30 fps 同步录屏。
2. **普通话配音**：使用 Microsoft Edge Neural TTS `zh-CN-XiaoxiaoNeural` 以从容语速（`-5% / -6%`）本地脚本生成（[`source/generate_vo.py`](../source/generate_vo.py)），经 48 kHz 统一重采样、高通滤波与透明压缩处理，剪辑阶段零加速。
3. **轻巧过渡音效与衬底**：由 [`source/generate_sfx_and_music.py`](../source/generate_sfx_and_music.py) 原创程序化合成（纸卡划过、箔面微光、潮玩按键弹跳与 118 BPM 柔和木琴衬底），仅用于片头、章节过渡与工坊设计静默期，所有产品试听、对比、变奏与剧场段落均完全退让产品真声。
4. **动态包装、章节卡与封面**：复用项目 `08_assets/optimized/` 官方实绘资产与真实导出的 `#MY-01`/`#MY-02` 海报、WebM 与 WAV 文件，通过 [`source/render_motion_packages.py`](../source/render_motion_packages.py) 确定性渲染。
